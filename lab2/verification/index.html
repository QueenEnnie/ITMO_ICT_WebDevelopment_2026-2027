Запуск и проверка¶

Запуск приложения¶

Требуются Go 1.25 или новее и запущенная PostgreSQL. Пользователь базы должен быть владельцем базы приложения. Команды выполняются из каталога laboratory_work_2.

В PowerShell задайте строку подключения, заменив YOUR_PASSWORD паролем пользователя PostgreSQL:

$env:DATABASE_URL = 'postgres://homework:YOUR_PASSWORD@127.0.0.1:5432/homework?sslmode=disable'
go run ./cmd/app

В командной строке Windows (cmd):

set "DATABASE_URL=postgres://homework:YOUR_PASSWORD@127.0.0.1:5432/homework?sslmode=disable"
go run ./cmd/app

Приложение создаёт таблицы при первом подключении. Откройте в браузере http://127.0.0.1:8080, зарегистрируйте учителя с ключом из internal/auth/teacher_key.go, войдите и добавьте предметы и задания. Для проверки роли ученика создайте отдельный аккаунт. Остановка приложения — Ctrl+C.
