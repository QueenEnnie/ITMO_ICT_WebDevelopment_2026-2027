# ЛР2: доска домашних заданий

Вариант 2, номер в журнале 26

## Что реализовано

- Регистрация учеников без ключа и учителей по специальному ключу, вход и выход.
- Предметы и задания: учитель, дата выдачи, срок, текст и штрафы.
- Поиск, фильтр по предмету, по 6 заданий на странице.
- Текстовый ответ ученика, изменение ответа до выставления оценки.
- Интерфейс учителя: создание, редактирование, удаление заданий и оценивание ответов.
- Общий журнал всех учеников, оценки от 2 до 5.
- Отметка просрочки. Штраф применяет учитель вручную при оценивании.

## Запуск

Требуются Go 1.25 или новее и PostgreSQL. Команды выполняются из папки этого проекта.

### 1. База данных

В установленной PostgreSQL создайте пользователя и отдельную базу. Например, выполните в psql под администратором (каждую команду отдельно):

```sql
CREATE USER homework WITH PASSWORD 'YOUR_PASSWORD';
CREATE DATABASE homework OWNER homework;
```

Вместо `YOUR_PASSWORD` укажите собственный пароль. Если база уже создана, используйте её имя, пользователя и порт. При первом запуске приложение само создаёт таблицы.

### 2. Запуск приложения

В PowerShell:

```powershell
$env:DATABASE_URL = 'postgres://homework:YOUR_PASSWORD@127.0.0.1:5432/homework?sslmode=disable'
go run ./cmd/app
```

В командной строке Windows (cmd):

```bat
set "DATABASE_URL=postgres://homework:YOUR_PASSWORD@127.0.0.1:5432/homework?sslmode=disable"
go run ./cmd/app
```

Замените `YOUR_PASSWORD` паролем пользователя базы данных. Специальные символы пароля в URL нужно percent-encode. Для установленной PostgreSQL обычно нужен порт `5432`, а пользователь и пароль — ваши. `sslmode=disable` здесь предназначен для локальной базы.

Откройте http://127.0.0.1:8080. Войдите в существующий аккаунт или зарегистрируйтесь, выбрав роль ученика или учителя. Для учителя помимо личного пароля нужен специальный ключ. Он задан константой `TeacherRegistrationKey` в `internal/auth/teacher_key.go`. Ученикам ключ не нужен. Также он используется только при регистрации: для входа нужен только личный пароль аккаунта и логин.

Настройки задаются переменными окружения. Переменная `DATABASE_URL` нужна в каждом новом терминале запуска. Остановка сервера — Ctrl+C. После изменения шаблонов, стилей или кода перезапустите `go run ./cmd/app`: ресурсы встраиваются при сборке.

## Как проверить вручную

1. Зарегистрируйтесь учителем по ключу, войдите, добавьте предмет на странице «Предметы» и создайте задание со сроком и штрафами.
2. Выйдите и зарегистрируйте ученика.
3. Найдите задание через поиск и отправьте текстовый ответ.
4. Снова войдите учителем, откройте задание, выставьте оценку и комментарий.
5. Войдите учеником: проверьте оценку в задании и общем журнале.
6. Добавьте больше шести заданий, проверьте страницы и фильтрацию.

Ответы других учеников видит только учитель. Оценки всех учеников доступны в общем журнале. После оценки ученик не может менять ответ. Учителя имеют доступ ко всем заданиям. Предполагается, что доска используется одним классом (все ученики попадают в журнал вместе).

## Файлы

| Файл | Назначение |
|---|---|
| `cmd/app/main.go` | Точка входа и запуск HTTP-сервера |
| `internal/auth/` | Сессии, токены, проверка ролей и CSRF |
| `internal/handlers/` | HTTP-обработчики, маршруты и вывод страниц |
| `internal/db/` | Все SQL-запросы, подключение к PostgreSQL, создание схемы |
| `internal/models/` | Структуры пользователя, задания, ответа и журнала |
| `assets.go` | Встраивание схемы, шаблонов и статики в программу |
| `schema.sql` | Таблицы PostgreSQL |
| `templates/` | Общий `base.html` и разделы `auth/`, `assignments/`, `gradebook/`, `subjects/` |
| `static/style.css` | Оформление |
| `static/assignment-dates.js` | Проверка срока сдачи относительно даты выдачи в форме |
| `docs/` | Отчёт MkDocs |

Библиотеки: стандартные `net/http`, `html/template`, `database/sql`; драйвер `pgx`; `bcrypt` из `golang.org/x/crypto` для хеширования паролей. SQL использует параметры. Даты просрочки и время отправки отображаются по московскому времени.
